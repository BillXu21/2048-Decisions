# 2048 reinforcement learning: decisions and research history

This repository records what was tried, what worked, and why the conclusions changed. It does not distribute the implementation, weights, demonstrations, coursework, or raw experiment outputs.

1. Read [Project state](PROJECT_STATE.md) for the strongest checkpoints, completed work, and open questions.
2. Read the [Decision index](DECISIONS.md) for durable choices and their later revisions.
3. Use the [Experiment index](EXPERIMENT_INDEX.md) to find the chronological evidence, including failures and partial runs.
4. For authorized local access, use the [artifact index](references/artifact_index.md) and [reproduction guide](references/reproduction.md).

All source paths in backticks refer to the separate implementation workspace unless marked otherwise. The Markdown links navigate this repository. No training, gameplay evaluation, or benchmark was launched to produce this publication.
