# Verification and reproduction

This is a history archive, not executable training. Use authorized copies of the implementation and artifacts; do not write in the original workspace. Original packet READMEs include worker commands that **launch GPU work**. They are not report-generation commands. Do not run them to verify this archive.

## Read-only audit

1. Resolve the relative workspace paths in the [artifact index](artifact_index.md). From that workspace, compare `Get-FileHash -Algorithm SHA256 <relative-path>` (PowerShell) or `sha256sum <relative-path>` (WSL) to the table and source manifests. A hash match verifies file bytes, not the validity of a policy score.
2. CNN PPO: use `jax_experiments/ntuple_hybrid_v3/ppo_pilot_10m/results/confirmation.json`. For each row/mode, take the arithmetic mean and median of `per_game[mode].scores`; reach is `count(max_tiles >= threshold) / games`. For paired contrasts, subtract indexed scores before averaging or bootstrapping. Check selected file identities against `results/selection.json` and cross-check all six development arrays before claiming a selection. V3 BC final uses the same array convention in its own `results/final.json`, but different seeds.
3. Long TD: use `jax_experiments/afterstate_td/bc_initialized/results/aggregate.json` for per-milestone and final-selected `per_game` rows and `historical/*_final.json` for PPO/origins. `results/final_audit.json` gives milestone hashes and actual generated counts. `runs/td1/new_12000000.confirmation.json` is a **16-game guard confirmation**, not the 128-game final selected-TD evaluation. Reproducing the wrong mean from that file is not a contradiction. Held-out and development rows use different seeds. Check origin arithmetic separately from new/generated counters.
4. Recreating historical reports in an isolated authorized copy: `report.py` in TD packets and `final_audit.py` (or long-study `audit.py`) implement CPU analysis; original instructions use `JAX_PLATFORMS=cpu` for JAX auditing. These may write outputs, so inspect before executing and use a copy. Match the preserved JAX/NumPy/Optax environment and source snapshots rather than installing a current stack into the original workspace. Some historical diagnostics called gameplay; not all report-adjacent commands are safe for an arithmetic-only audit.

## Scope and limitations

- Consolidation recalculated V3 BC final and V3 PPO development/final score means, medians, tile reaches and paired point differences; reconciled V3 PPO chunk counts, optimizer steps, KL and clipping summaries from raw JSONL; checked long TD development and final means, final reaches and selected checkpoint provenance; and verified all 19 long-study milestone hashes against the final audit. This is independent arithmetic and file identity verification, **not independent policy replay, training, timing, or a claim that the reported bootstrap intervals were regenerated**.
- Historical V1 confirmation retains aggregate rows, not the paired arrays needed for its confidence intervals. Early MLP continuation reports contain corrected labels and CIs; use §12, not the superseded prose. Its partial search comparison was not audited. No source Git SHA was found; there are source hashes/snapshots, not a publicly buildable source revision. No later completed TD packet was found beyond the long run and separate rejected repair.
- For any separately authorized replication: pin checkpoint hashes, config, RNGs, dependency versions and device/precision flags. Pair methods under the same evaluation process, batch shape and streams; real uniform-empty spawn, 90/10 tile values, lowest legal argmax tie convention, complete games. Establish separate dev/final seed ranges and track training seeds independently. Full eight-way averaging, actor/critic config, and time-region definitions are material. Numerical near-ties can turn tiny logit changes into widely different trajectories. Resume exact optimizer and environment state or label the attempt a fork; do not revive guard-stopped arms.
- Public release contains only original research summaries, aggregate metrics, relative research paths, checkpoint hashes and public literature references. It excludes coursework and submission materials, instructor files, datasets, raw trajectories and logs, host/user identifiers, credentials, source, model blobs, environments and redundant/private figures. Any unverified or restricted provenance stays local.
